## Variant: Left rail workbench

### Design stance
A compact desktop instrument: controls and collapsible sections on the left, large synchronized visualizations on the right.

### Key choices
- Layout: left control rail, large Observer Sky and Local Horizon Geometry panels.
- Typography: compact, tabular, scientific.
- Color: restrained light surfaces with blue-grey structure and semantic Sun/Moon colors.
- Interaction: collapsible workbench sections and a time slider.

### Trade-offs
- Strong at: functional desktop workflow, avoiding card soup, keeping controls close.
- Weak at: less full-bleed visual drama than a canvas-first design.

### Best for
The main MoonGeometry application shell. This is the recommended baseline.
