## Variant: Top toolbar dual panels

### Design stance
A clean scientific web tool: compact top controls with side-by-side primary visualizations.

### Key choices
- Layout: top toolbar, dual equal-weight visual panels, timeline and explanation beneath.
- Typography: dense but readable.
- Color: restrained neutral workspace.
- Interaction: time slider, view tabs.

### Trade-offs
- Strong at: showing sky and geometry with equal status.
- Weak at: toolbar can become crowded as features grow.

### Best for
A simpler v1 if the left rail feels too heavy.
